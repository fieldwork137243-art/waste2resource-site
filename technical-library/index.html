How to use the library

Compare pathways, then return to the material.

A case can show that a pathway is plausible. It cannot prove that another residue will behave the same way. Use the records to identify precedents, test methods and deployment questions, then apply the Assessment Framework to a site-specific decision.

Evidence note: company and project disclosures are labelled as such. They are useful indicators of scale and activity, but do not carry the same evidentiary weight as independently reviewed performance data.
