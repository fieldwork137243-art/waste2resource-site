Why this exists

Closing the gap between a promising test and a workable project.

Laboratory feasibility is an important signal, but it is not the same as commercial readiness. Tailings vary by geology, processing history, storage conditions and exposure pathway, so credible reuse must be built on site-specific evidence.

Waste2Resource connects material characterisation, performance testing, environmental behaviour and deployment constraints in one engineering-led view. From an Australian perspective, it asks how mine-derived materials can move responsibly into infrastructure, rehabilitation and circular-economy applications.

Engineering pathway

From residue question to deployment decision.

A credible reuse pathway advances through evidence gates. Each stage can redirect the concept, identify more test work or stop an unsuitable pathway before scale-up.

  1. 01
    Frame

    Define the problem

    Volume, liability, closure objective and potential value.

  2. 02
    Characterise

    Read the material

    Variability, mineralogy, geochemistry and particle behaviour.

  3. 03
    Test

    Generate evidence

    Performance, release behaviour, durability and processing demand.

  4. 04
    Assess

    Pass the gates

    Specifications, environment, logistics, market and approvals.

  5. 05
    Deploy

    Prove the fit

    Pilot, quality controls, monitoring and commercial delivery.
